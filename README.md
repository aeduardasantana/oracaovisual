# Oração Visual

Aplicação web católica, mobile-first, para apoiar o hábito da oração diária por meio de imagens, palavras curtas e uma sequência guiada de louvor, perdão, pedido e agradecimento.

## Princípios

- a imagem é a linguagem principal;
- cada imagem possui palavra ou frase curta para leitura pelo VLibras;
- Maria e São José aparecem como intercessores junto a Jesus;
- toda oração termina com “Em nome de Jesus. Amém.”;
- o histórico permanece somente no navegador da pessoa.

## Uso

Abra `index.html` ou publique o repositório pelo GitHub Pages. Não há banco de dados nem etapa de instalação.

## Imagens

A ilustração principal foi criada originalmente para este projeto. Novas imagens podem ser cadastradas em `app.js`; registre sempre título, texto alternativo, origem, autor e licença.
